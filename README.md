# CodeCraftHub

## Project Overview

CodeCraftHub is a personal learning goal tracker API built with Node.js and Express. It lets developers record courses, target dates, descriptions, and learning progress. Course records are stored in the local `courses.json` file; no database, authentication, or user management is included.

Project metadata is defined in `package.json`:

- **Name:** `codecrafthub`
- **Version:** `1.0.0`
- **Description:** Personal learning goal tracker API

## Features

- Create, list, view, update, and delete courses.
- View total course and status statistics.
- Generate numeric course IDs starting at 1.
- Record an automatic ISO `created_at` timestamp for every course.
- Validate required fields, real `YYYY-MM-DD` dates, and allowed statuses.
- Create `courses.json` automatically when it does not exist.
- Return clear `400`, `404`, and `500` JSON error responses.
- Persist course changes locally with Node.js file operations.

## Requirements

- Node.js 20 or newer
- npm

## Installation

```bash
npm install
```

## How to Run

Start the application with:

```bash
npm start
```

The `start` script runs `app.js`, and the server listens on port `5000`.

For automatic restarts during development:

```bash
npm run dev
```

The API creates `courses.json` automatically with an empty array if the file does not exist.

## Course Model

```json
{
  "id": 1,
  "name": "REST API Fundamentals",
  "description": "Learn HTTP methods, status codes, routing, and JSON responses.",
  "target_date": "2026-10-15",
  "status": "Not Started",
  "created_at": "2026-09-22T12:00:00.000Z"
}
```

Required request fields are `name`, `description`, `target_date`, and `status`. The target date must be a real date in `YYYY-MM-DD` format. Allowed statuses are `Not Started`, `In Progress`, and `Completed`. IDs and timestamps are generated by the server.

## REST API

All endpoints use the `/api/courses` resource. The `:id` placeholder is the numeric course ID.

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/courses` | Add a new course |
| `GET` | `/api/courses` | Get all courses |
| `GET` | `/api/courses/stats` | Get total and status statistics |
| `GET` | `/api/courses/:id` | Get one course |
| `PUT` | `/api/courses/:id` | Update a course |
| `DELETE` | `/api/courses/:id` | Delete a course |

### Create or Update Request

```json
{
  "name": "REST API Fundamentals",
  "description": "Learn HTTP methods, status codes, routing, and JSON responses.",
  "target_date": "2026-10-15",
  "status": "In Progress"
}
```

Example create request:

```bash
curl -X POST http://localhost:5000/api/courses \
  -H "Content-Type: application/json" \
  -d '{"name":"REST API Fundamentals","description":"Learn HTTP methods and JSON responses.","target_date":"2026-10-15","status":"Not Started"}'
```

Example list request:

```bash
curl http://localhost:5000/api/courses
```

Example statistics request:

```bash
curl http://localhost:5000/api/courses/stats
```

Example statistics response:

```json
{
  "total_courses": 2,
  "by_status": {
    "Not Started": 2,
    "In Progress": 0,
    "Completed": 0
  }
}
```

Example get-one request:

```bash
curl http://localhost:5000/api/courses/1
```

Example update request:

```bash
curl -X PUT http://localhost:5000/api/courses/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"REST API Fundamentals","description":"Updated course description.","target_date":"2026-10-15","status":"Completed"}'
```

Example delete request:

```bash
curl -X DELETE http://localhost:5000/api/courses/1
```

### Response Status Codes

- `200 OK` for successful reads and updates
- `201 Created` for a successful create
- `204 No Content` for a successful delete
- `400 Bad Request` for missing or invalid fields and malformed JSON
- `404 Not Found` when a course ID does not exist
- `500 Internal Server Error` for file or unexpected application errors

## Troubleshooting

### `npm` or `node` is not recognized

Install Node.js 20 or newer, then open a new terminal so the Node.js installation is available on your system `PATH`.

### Port 5000 is already in use

Stop the process using port 5000, then run `npm start` again. On Windows PowerShell, identify the process with:

```powershell
Get-NetTCPConnection -LocalPort 5000
```

### The API cannot read or write `courses.json`

Make sure the project directory is writable and that `courses.json` contains a valid JSON array, such as `[]`. File access errors and invalid JSON are returned as HTTP 500 responses.

### A request returns HTTP 400

Send JSON with `Content-Type: application/json` and include non-empty `name`, `description`, `target_date`, and `status` fields. Use a real date such as `2026-10-15` and one of the allowed statuses: `Not Started`, `In Progress`, or `Completed`.

### A request returns HTTP 404

Confirm that the course ID exists and that the URL includes the numeric ID, for example `/api/courses/1`.

## Limitations

- JSON file storage is intended for a small local learning project.
- Each mutation rewrites the complete file.
- Concurrent writes and multiple application instances are not supported.
- There is no authentication, so deploy only in a trusted environment.
